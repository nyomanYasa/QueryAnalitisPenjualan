Judul Proyek : Online Retail Sales & Customer Behavior Analysis using PostgreSQL

Latar Belakang : Menjelaskan bahwa menganalisis ribuan transaksi e-commerce untuk membantu manajemen memahami pola pembelian pelanggan dan produk terlaris.

Skema Database : Menampilkan ringkasan struktur tabel (invoice_no, stock_code, quantity, unit_price, customer_id, dll).

Tujuan bisnis : Mengelompokkan Pelanggan berdasarkan perilaku belanja mereka menggunakan metode RFM (Recency, Frequency, Monetary) agar perusahaan dapat memberikan penawaran pemasaran yang tepat sasaran.

Teknik SQL yang digunakan : Common Table Expressions (CTE) berantai, Aggregate Functions, Conditional Logic (Case When), dan Date Arithmetic.
